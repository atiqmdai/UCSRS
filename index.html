UCSRS v1.0 — Universal Cardiac Surgical Risk Score

Implements the algorithm exactly as specified in Section 3.3 of J Cardiothorac Surg 2026, DOI 10.1186/s13019-026-04433-x · research tool, not for sole clinical decision-making

Tier 1 — Clinic
Tier 2 — Enhanced pre-op
Tier 3 — Full cath lab

Layer 1 — Clinical variables

Weight of intervention is set automatically from the procedure and can be overridden.

Layer 2b — Clinical Frailty Scale (required)

Assessed at the last pre-operative encounter.

Layer 2a — MELD (optional)

Layer 2c — LV dimensions and SYNTAX (optional)

LVESVI takes precedence; LVEDD is used only when LVESVI is unavailable. Enter 0 for angiographically normal or non-obstructive coronaries.

Layer 3 — RHC haemodynamics (Tier 3 only)

Echo sPAP does not substitute for RHC PASP in the TAPSE/PASP ratio.
